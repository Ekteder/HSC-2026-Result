### B. Result Sheet API Endpoint Pattern
- URL: `https://www.jessoreboard.gov.bd/resultjbh26/result_sheet.php?eiin={eiin}`
- Method: `GET`
- Payload: Standard HTML document containing grouped blocks `<div class="group_title">Group : {Group Name}</div>` and `<div class="result">{Roll}[{GPA/Status}]</div>`.
- Result statuses encountered:
  - Numeric decimal: `5.00`, `4.50`, etc. (Successful / Passed)
  - `Fail`: Generic fail across multiple subjects
  - `F1`: Failed in 1 subject
  - `F2`: Failed in 2 subjects
  - `Abst`: Absent in examination
  - `Expl`: Expelled during examination

### C. Individual Student Marksheet Query Endpoint
- URL: `https://www.jessoreboard.gov.bd/resultjbh26/result.php`
- Method: `POST`
- Form fields:
  - `roll`: 6-digit roll number
  - `regno`: registration number (optional for basic results, required for full subject marksheet)
- Output: HTML snippet containing student name, father's name, mother's name, center name, institute name, stream, subject-wise grades, and marks.
